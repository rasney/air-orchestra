# Air Orchestra — 原型说明

## 怎么运行

1. 用 Chrome 或 Edge 打开 `index.html`（需要联网，库和手势模型从网上加载）。
2. 点 **Start**，允许摄像头权限。
3. 站在摄像头前 0.5–2 米，正面光线充足，举手就能开始玩。

如果双击打开后摄像头不工作，在文件所在文件夹运行：

```
python3 -m http.server 8000
```

然后浏览器打开 `http://localhost:8000`。

## 交互设计

| 动作 | 效果 |
| --- | --- |
| 食指指尖上下移动 | 音高（锁定在音阶上，乱挥也好听） |
| 食指指尖左右移动 | 音色明暗（左边闷、右边亮） |
| 拇指和食指捏合 | 打鼓：一只手是底鼓，另一只是镲 |
| 手离开画面 | 声音淡出 |
| 两只手 / 两个人 | 两个声部：一个柔和（三角波），一个明亮（锯齿波） |

画面：手指带着发光拖尾，颜色随音高变化；捏合时炸开一圈粒子；背景横线标出每个音的位置。

键盘：`1` `2` `3` 切换音阶（五声 / 大调 / 小调五声），`V` 开关摄像头画面，`D` 显示手部关键点。

## 可以调的参数

都在代码开头的 `CONFIG` 里：

- `smoothing`：越小越平滑、越不抖，但跟手会慢一点
- `pinchOn` / `pinchOff`：捏合灵敏度，误触发多就把 `pinchOn` 调小
- `noteHysteresis`：在两个音交界处来回跳的话就调大
- `SCALES`：可以换音阶，或者增减音域

## 接下来可以做的（按优先级）

1. **调手感**：几个人轮流试玩，调好上面的参数和音色。
2. **双人模式打磨**：目前两只手就是两个声部，可以改成"每个人一个声部"。
3. **Loop 录音**：录几秒自动循环，再在上面叠加新的声部。
4. **用户测试**：找 5–8 人试玩，填一个简短问卷，写进报告。
5. **展示准备**：提前去教室试灯光和投影。

## 用到的东西

- MediaPipe Hand Landmarker：手部识别
- Tone.js：发声
- 浏览器 Canvas：画面效果
